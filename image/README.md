# Fission Research identity

The research identity extends the circuit-trace **F** and blue/violet/orange
palette of [Fission](https://github.com/fission-systems/Fission). An open violet
terminal adds an experimental branch to the shared mark.

| Asset | Use |
|---|---|
| [`fission-research-logo.svg`](fission-research-logo.svg) | Horizontal wordmark on light backgrounds. |
| [`fission-research-logo-dark.svg`](fission-research-logo-dark.svg) | Horizontal wordmark on dark backgrounds. |
| [`fission-research-mark.svg`](fission-research-mark.svg) | Square icon; the tile works on either background. |

All assets are self-contained SVGs with outlined lettering, accessible titles
and descriptions, transparent outer backgrounds, and no font, script or external
image dependencies. The README selects a wordmark with a `<picture>` element.

The trace geometry and palette derive from Fission's
[`image/fission-mark.svg`](https://github.com/fission-systems/Fission/blob/cb7b12f5c0c5c6790de58db3d0ef0de05e826d91/image/fission-mark.svg),
under Apache-2.0. The research branch and wordmark composition are maintained here.
Use the light wordmark as the default when theme selection is unavailable.
